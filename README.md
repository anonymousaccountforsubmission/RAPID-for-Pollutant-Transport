# RAPID

RAPID is a physics-informed neural network surrogate for AERMOD that models benzene, NO₂, and SO₂ dispersion across the Houston Ship Channel.

This repository contains:

* AERMOD-generated training data and metadata
* PyTorch training scripts for all three pollutant models
* Physics-informed advection–diffusion–reaction formulations
* Model evaluation and visualization code

See the README files within each folder for usage details.
